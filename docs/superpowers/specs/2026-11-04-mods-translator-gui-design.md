# أداة ترجمة المودات الإضافية: واجهة رسومية + ذاكرة ترجمة + ترجمة تزايدية

**التاريخ:** 2026-11-04 · **قرارات المستخدم:** للاعبين أيضاً (Python مدمج)، نافذة مستقلة يفتحها زر في
`Change-Language.ps1`، التنفيذ مباشرة، والتوقف فقط قبل `git push` وقبل النشر على موقع المودات.

## الهدف وشرط الانتهاء

- واجهة WinForms عربية RTL تعمل على PowerShell 5.1، والخلفية `tools/modpack.py`.
- ذاكرة ترجمة مشتركة بين المودات، مفهرسة بالنص الإنجليزي، ومسرد كلمات مفردة يُرسَل مع كل طلب.
- ترجمة تزايدية: مود لم يتغيّر لا يُرسل عنه أي طلب API، ومود تغيّر تُترجم نصوصه الجديدة أو المتغيّرة فقط.
- **يثبت بالقياس:** التشغيل الثاني على المودات نفسها يُرسل 0 طلب API.

## تدفّق البيانات

```
mods/ ─► enabled_mods ─► load_order ─► النص الإنجليزي الفائز لكل مفتاح
   لكل مفتاح: override(key) > عربية المود > اسم تجاري > TM اللعبة الأساسية > TM المشتركة > طلب API
   طلبات API: دفعات + المسرد المطابق فقط ← تحقّق check_value ← تُخزَّن في TM المشتركة بالنص الإنجليزي
 ─► visual_value ─► arabic-mods-local ─► Install-FAPack
 ─► manifest لكل مود (الإصدار، بصمة النصوص، مفتاح ← بصمة النص) + usage.json + reports/modpack.md
```

- **TM المشتركة:** `STATE/memory.json`، مفتاحها `sha1(النص الإنجليزي بعد ضغط المسافات)`، وتحفظ النص نفسه
  للمطابقة ثم المطابقة دون حساسية لحالة الأحرف. `STATE` = `work/modpack` للمطوّر، و
  `%APPDATA%\Factorio\arabic-tools\translator` للاعب (تبقى عند تحديث الأداة).
- **TM اللعبة الأساسية:** من `src/ar` للمطوّر، ومن مود `arabic-complete` المثبّت للاعب (NFKC + `from_visual`).
  لا يُشحن أي نص إنجليزي من اللعبة.
- **المسرد:** `glossary.json` (1,055) + أسماء النماذج من اللعبة الأساسية (`item-name`, `entity-name`, `fluid-name`,
  `recipe-name`, `technology-name`, ... حتى 3 كلمات)، مثل water ← ماء. يُرسل منه ما يظهر في الدفعة فقط (60 حداً أقصى).
- **ترحيل:** `cache.json` القديم (مفهرس بالمفتاح) يُقرأ مرة ويُنقل إلى TM دون حذفه.
- **التصحيحات اليدوية** (`modpack_overrides.json`) تغلب دائماً ولا تُكتب في TM.

## حالات المود في الواجهة

| الحالة | الشرط |
|---|---|
| مترجم | موجود في manifest بالبصمة نفسها، ولا نص ينتظر |
| جديد | غير موجود في manifest |
| تغيّر | البصمة تغيّرت (الإصدار أو النصوص)؛ يُعرض عدد النصوص الجديدة/المتغيّرة |
| ينتظر الترجمة | البصمة نفسها، وبقيت نصوص بلا عربية (لا مفتاح أو فشل) |

## قياس الاستهلاك والتوفير

- كل طلب يعيد `usage` الحقيقي: OpenAI `usage.prompt_tokens/completion_tokens`، Anthropic `usage.input_tokens/output_tokens`،
  DeepL عدد الأحرف.
- لكل تشغيل: الطلبات، التوكن الداخل والخارج، حصة المسرد من الداخل (بنسبة أحرفه في الطلب)، والنصوص المخدومة من TM.
- **التوفير المقدّر** = عدد نصوص TM × متوسط التوكن لكل نص من الطلبات الفعلية. يُكتب في التقرير والواجهة.
- المسرد **يضيف** توكن لكل طلب ولا يغني عن ترجمة الجملة، ويُذكر ذلك بالأرقام.

## الأخطاء والتراجع

- خطأ المزوّد أو الشبكة: الدفعة تُسجَّل وتبقى نصوصها بالإنجليزية، ولا يتوقف البناء.
- مفتاح مرفوض: لا يُحفظ.
- التراجع: زر في النافذة / `translate_mods.ps1 -Uninstall` (ركن الحزمة دون حذف)، و`git revert` للكود.
  ملفات `STATE` تُترك كما هي.

## الاختبار

- وحدات: TM (مطابقة، حالة الأحرف، ترحيل)، TB، الحالات، الاستهلاك، التقدّم.
- تكامل: خادم محلي متوافق مع OpenAI يعدّ الطلبات: التشغيل الأول > 0، والثاني = 0.
- المحرك: تفريغ نصوص اللعبة على نسخة معزولة: نصوص pump عربية وchecksum = 0.
- اللاعب: فكّ `arabic-mods-translator.zip` في مجلد مؤقت، وتشغيل البناء بـ Python المدمج.
- لقطات حقيقية للنافذة (`-Snapshot`).
